# CampusKala

CampusKala is a front-end prototype for a student campus marketplace. It is designed to solve one simple workflow: helping students discover, save, and share campus-related items and services in one interactive web page instead of relying on scattered chats, posters, and word of mouth.

## Project Aim

To design and develop an interactive front-end prototype that demonstrates:

- HTML5 semantic structure
- Responsive UI with CSS and utility classes
- JavaScript event handling
- Forms with client-side validation
- HTML5/browser APIs such as `video`, `canvas`, `localStorage`, and `IntersectionObserver`

## Problem Statement

Students often need a simple way to browse or promote campus-related products and services such as notes, food, handmade items, tutoring, and study essentials. The current process is usually fragmented across multiple platforms. CampusKala brings this into a single, user-friendly interface.

## Target Users

- College students
- Student sellers
- Campus entrepreneurs
- Buyers looking for local campus items and services

## Features Implemented

- Full-screen hero section with background video
- Smooth scrolling navigation
- Responsive layout for desktop and mobile
- Interactive product cards
- Search and category filtering
- Join form with client-side validation
- LocalStorage support for saved items and counters
- Canvas-based activity visualization
- Mouse sparkle interaction effect
- Active navigation state using `IntersectionObserver`

## Technologies Used

## How to Run

1. Keep `campuskala.html` and the video file in the same folder.
2. Open `campuskala.html` in a browser.
3. Use the navigation menu, filters, form, and interactive sections.

## Limitations

- No backend/database
- No real login system
- No payment integration
- No actual chat system
- Data is stored only in the browser using `localStorage`
- Listings are demo content for prototype purposes
